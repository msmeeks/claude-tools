About this demo

We start with the problem: you've shipped a feature and need a demo, but you don't have a video team. demo-gen solves this in one command — no cloud services, no subscriptions, no data leaving your machine.

1

Install demo-gen and its dependencies

Terminal
$ brew install ffmpeg
$ pip install demo-gen
Successfully installed demo-gen-0.1.0
$ ollama pull llama3.2
pulling manifest... done
$ demo-gen download-models --tts-only
✓ kokoro/kokoro-v1_1.onnx
Three tools to install: ffmpeg (video), Ollama (local LLM for scripting), and the TTS models. Takes about 3 minutes on a fresh machine.
2

Run demo-gen generate with your product and feature

Terminal
$ demo-gen generate \
  --product "My App" \
  --feature "User Onboarding" \
  --polish standard \
  --format both \
  --output-dir ./output

Stage 1/6: Generating script…
Stage 2/6: Loading assets…
Stage 3/6: Generating voiceovers…
Stage 4/6: Rendering slides…
Stage 5/6: Assembling video…
Stage 6/6: Rendering HTML…
Done.
  HTML: output/user-onboarding.html
  MP4:  output/user-onboarding.mp4
The six-stage pipeline runs in sequence. On an M-series Mac with Kokoro TTS, a standard-polish 4-step demo takes around 30 seconds.
3

Open the HTML script and the MP4 video

Browser — output/user-onboarding.html
The HTML script is a fully self-contained file — no external dependencies. Share it by email or host it on any static file server. The MP4 has burned-in subtitles and a voiceover matched to each step.
4

Add real screenshots for richer output

Terminal
# Take screenshots of your UI, then pass them in order
$ demo-gen generate \
  --product "My App" \
  --feature "User Onboarding" \
  --screenshot screenshots/step1-welcome.png \
  --screenshot screenshots/step2-profile.png \
  --screenshot screenshots/step3-done.png \
  --polish production \
  --format both \
  --output-dir ./output
With --polish production, demo-gen adds a red highlight annotation ring to each screenshot and includes callout labels in the HTML. Pass screenshots in the order they should appear in the demo.

Key Takeaways

  • demo-gen runs entirely on your machine — no cloud services required by default
  • One command produces both an HTML script and an MP4 video with voiceover
  • Pass real screenshots with --screenshot to upgrade from placeholder mocks
  • --polish production adds annotation rings, callout labels, and better audio
  • The output HTML is fully self-contained — share it anywhere without dependencies
