About this demo

Every project has its own color palette, tone of voice, and terminology. demo-gen uses a simple design_tokens.json file and a BRAND_VOICE.md to match your brand exactly — from the header gradient down to the caption text color.

1

Create a design_tokens.json file for your project

design_tokens.json — Acme (purple brand)
{
  "brand_gradient_start": "#4c1d95",
  "brand_gradient_end": "#6366f1",
  "brand_primary": "#6366f1",
  "brand_primary_light": "#e0e7ff",
  "brand_primary_dark": "#3730a3",
  "highlight_color": "#f59e0b", // amber instead of red
  "page_bg": "#f8fafc",
  "tagline": "Move faster with Acme."
}
You only need to provide the keys you want to override. Every missing key falls back to demo-gen's defaults. The full list of available keys is in the API reference.
2

Write a BRAND_VOICE.md to match your tone

BRAND_VOICE.md
# Brand Voice — Acme Platform

## Product
**Name:** Acme Platform
**Tagline:** Move faster with Acme.

## Voice attributes
Confident, precise, fast, developer-friendly.

## Writing rules
- Lead with outcomes, not features.
- Use "you" (second person), active voice.
- Keep sentences under 18 words.
- Never say "leverage", "synergy", or "seamless".

## Demo tone
Pace: 160 wpm. Opening: state the pain, then the fix.
demo-gen reads BRAND_VOICE.md before generating any script content. The LLM uses your voice rules directly — tone, terminology, sentences to avoid — so the output sounds like you wrote it.
3

Pass --tokens and --brand-voice to demo-gen generate

Terminal
$ demo-gen generate \
  --product "Acme Platform" \
  --feature "Reports" \
  # point to your branding files
  --tokens ./acme-tokens.json \
  --brand-voice ./BRAND_VOICE.md \
  --polish production \
  --format both \
  --output-dir ./help-docs/demos/features/
Both flags are optional — pass them together for the best results. --tokens controls the visual output; --brand-voice controls the script's language and tone.

The same demo script, two completely different brand identities. Design tokens propagate to every element: header gradient, step circles, caption borders, takeaways section, and video slides.

Key Takeaways

  • Design tokens control all colors in both HTML output and video slides
  • Only supply the keys you want to override — defaults handle the rest
  • BRAND_VOICE.md shapes the script's language, not just the visuals
  • Bundled presets include hospitality-scheduled.json — copy and adapt for your own project
  • Branding changes take effect immediately on the next demo-gen generate run
