Example — full production demo

demo-gen generate \
  --product "Acme Platform" \
  --feature "Reports" \
  --brand-voice ./BRAND_VOICE.md \
  --include-docs ./docs/features/reports.md \
  --screenshot screenshots/report-list.png \
  --screenshot screenshots/report-builder.png \
  --tokens ./acme-tokens.json \
  --polish production \
  --tone professional \
  --voice am_adam \
  --format both \
  --output-dir ./help-docs/demos/features/

demo-gen download-models

Download AI model weights to ~/.demo-gen/models/.

demo-gen download-models [--tts-only] [--force]
FlagDescription
--tts-onlyDownload TTS models only (Kokoro ONNX)
--forceRe-download even if already present; re-verifies SHA-256
All downloads use HTTPS. SHA-256 checksums are verified against a pinned manifest before any model is loaded.

Pipeline stages

demo-gen runs six stages in sequence. All intermediate files live in a temporary directory that is deleted on completion (including on error).

1

Script generation — demo_gen/stages/script.py

Calls Ollama (local) or Claude API (cloud) with a structured prompt and returns a DemoScript Pydantic object: title, tagline, executive summary, steps, takeaways, CTA. File contents passed via --include-docs are XML-delimited in the prompt to prevent prompt injection.

2

Asset loading — demo_gen/stages/assets.py

Validates and loads all input screenshots and recordings. All paths are canonicalized, checked against an allowed extension list, and must resolve within the home directory or cwd. Recordings are frame-extracted with MoviePy. Images are letterboxed to the target resolution with Pillow.

3

Voiceover synthesis — demo_gen/stages/voice.py

Synthesizes per-step audio from the talk track text. Backend is selected by polish level: KokoroBackend (standard/production), PiperBackend (draft, if installed), or NullBackend (silence). Output: one WAV per step at 24kHz.

4

Slide composition — demo_gen/stages/slides.py

Renders title card, per-step slides, and closing card as PNG images using Pillow. All colors come from the design token dictionary. Screenshots are composited onto step slides at full resolution.

5

Video assembly — demo_gen/stages/video.py

Converts each PNG slide to a video clip matching the audio duration, muxes with per-step WAV, concatenates all clips, then burns SRT subtitles. All ffmpeg calls use shell=False with explicit argument lists. SFX is generated inline via the ffmpeg sine source filter.

6

HTML rendering — demo_gen/stages/html.py

Renders the canonical Variant-B HTML template via Jinja2 with autoescape=True. All AI-generated content is passed as render-time variables — never as template source — preventing SSTI. Design tokens are injected directly into CSS. Screenshots are copied to an assets/ subdirectory alongside the HTML.
